# Configuration Guide

These files are CLI snippets and endpoint inventories for the eNSP lab.

| File | Role |
|---|---|
| `FW-Bank.txt` | USG6525E interfaces, zones, routes, security policies, NAT, and attack defense |
| `R-Internet.txt` | Simulated Internet router |
| `R-Attacker.txt` | Security-test router |
| `R-BackOffice.txt` | BackOffice gateway configuration |
| `PCs.txt` | PC addressing and zone inventory |
| `Server.txt` | Server addressing and service inventory |
| `Verification.txt` | Functional and security verification commands |

Apply configurations only to the matching device in the isolated eNSP topology. Review interface numbering and command support when using a different Huawei image.
